# 🍽️ Magic Spoon Restaurant Website

A modern and responsive restaurant website designed for **Magic Spoon Restaurant**.

## 📌 Project Overview

Magic Spoon is a restaurant website created using **HTML and Tailwind CSS**.
The website provides information about the restaurant, menu, events, blog/news, and contact details.

## ✨ Features

* 🏠 Home page
* 🍴 Restaurant Menu
* 🎉 Entertainment & Events
* 📖 About / Our Story
* 📰 Blog & News
* 📅 Reservations
* 📞 Contact Us
* 🖼️ Gallery
* 🏢 Private Dining & Corporate Bookings
* 📱 Responsive design
* 🎨 Modern restaurant UI
* ✉️ Contact and newsletter forms

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* CSS
* Google Fonts
* Unsplash Images

## 🎨 Design

The website uses:

* Black background sections
* Cream/light background sections
* Gold accent colors
* Fraunces and Inter fonts
* Responsive Tailwind CSS layouts
* Restaurant-themed images

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `home.html` in your browser.
4. Navigate through the website using the navigation bar.

## 📱 Responsive Design

The website is designed to work on:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet

Tailwind CSS responsive classes are used throughout the pages.
